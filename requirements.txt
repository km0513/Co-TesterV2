# Installation Instructions

# 1. Install Python dependencies:
#    pip install -r requirements.txt
#
# 2. Install browser-use (AI-powered browser automation):
#    pip install git+https://github.com/browser-use/browser-use.git
#
# 3. Install Playwright browsers:
#    playwright install
#
# 4. Install Node.js dependencies (for MBT XState integration):
#    npm install
#
# 5. Configure environment variables in .env:
#    - GEMINI_API_KEY (required for AI features)
#    - OPENAI_API_KEY (optional, for OpenAI backend)
#    - DATABASE_URL (optional, defaults to SQLite)
#    - SECRET_KEY (required for Flask sessions)
