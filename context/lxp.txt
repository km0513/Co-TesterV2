### Chunk 1 — LMS Structure & Hierarchy
```
Entities & Relationships:
- Program → contains Courses
- Course → contains Modules
- Module → contains Sessions & Segments
- Segment → contains Assets

Asset Locking:
- On enrollment, only first asset of first module in each course is unlocked.
- Next asset unlocks only when previous asset is completed.

Sequential vs Non-Sequential:
- Containers can be sequential or non-sequential.
- Sequential: learner must finish prior container before next unlocks.
- Availability & Due Dates apply at each container level.
```
---

### Chunk 2 — Asset Types & Behaviors
```
Asset Types:
1. Video
2. PDF/Document
3. Graded Assessment (MCQ, MSQ)
4. Assignments (Manual-graded / Auto-graded)
5. Super Asset (Video + Text)
6. Recall Quiz (Non-graded)

Behavior:
- Videos: Watch Now; bookmarks at timestamp.
- PDFs: viewer with bookmark by page.
- Graded Assessments: immediate scoring.
- Assignments: submission workflow, grading panel (lenient/strict).
- Super Assets: combined media/text view.
- Recall Quizzes: no score stored.
- Notes: free text notes, timestamped, linked to asset.
```
---

### Chunk 3 — Enrollment & Access Rules
```
Enrollment:
- Program enrollment → all courses visible.
- Enrollment date captured; drives availability.

Access Control:
- Assets locked/unlocked per sequence & due dates.
- Direct URL to locked asset → “Access Denied”.
- Admin/Delivery Manager bypasses locks.

Guest Link:
- Temporary URL for external learners/instructors.
- Guest cannot submit or see dashboards.
```
---

### Chunk 4 — Assignment Submission, Grading & Penalties
```
Manual Assignments:
- File upload before due date.
- Post-due: request extension (reason, days).

Auto-Graded Assignments:
- System checks answer key → instant feedback.

Grading Panel:
- Submission details (timestamp, file link).
- Marks entry with strict/lenient schema.
- Deferral tag visible on scorecard if deferred.

Penalty Logic:
- Parameters: penalty_percent_per_day, grace_period_days, max_penalty.
- Late submission beyond grace → final_score reduced.
- Floor at 0, cap applies.
- Known bug: penalties exceeded cap in some cases (fixed).
```
---

### Chunk 5 — Program Versioning & Cohort Logic
```
Versioning (IRA-59024 → 59090):
- Cohort-specific curriculum versions.
- New versions apply only to new/future cohorts.
- Completed cohorts locked.
- Current cohorts → upgrade rules differ for graded vs non-graded assets.

Cohort Cloning:
- Copy curriculum to another cohort.
- Option: include drafts.

Learner Impacts:
- Scorecards updated on replacement.
- Help tickets raised if mismatch occurs.
```

### Chunk 6 — Sessions & Live Class Management
```
Types: Zoom, UGlive, External.
Attendance: logged when learner clicks “Join”.
Recordings: “Watch Now” post-session, retention configurable.

Reschedule/Cancel:
- Notifications sent to learners/instructors.
- UI shows “Rescheduled” / “Cancelled”.

Enhancements:
- Session groups for multiple sessions.
- Delivery Managers/Mentors can edit session windows/resources.
```
---

### Chunk 7 — Evaluator Allocation
```
Auto-Allocator:
- Input: evaluator-to-assignment CSV.
- Modes: Round-Robin, Load-based.

Rules:
- Skip evaluators with capacity=0.
- Active load updated dynamically.

Manual Override:
- Adjust load/capacity → triggers reallocation.

Error Handling:
- Invalid CSV rows → downloadable error file.
```

### Chunk 8 — Help & Support
```
My Queries:
- Tabs: Open, Closed.
- Default view: queries ≤120 days.
- Bug: older queries not retrievable.

Admin/DM Bypass:
- Full query visibility (beyond 120 days).

Empty State:
- “No Queries Found” with header/subtext.
```

### Chunk 13 — Duplicate & Rollback Handling
```
Duplicate Prevention:
- Detect and warn: “Asset already exists”.

Rollback:

```

### Chunk 14 — Error Pages & Edge Cases
```
Error Screens:
- 404 custom page with support link.
- Unsupported Browser page.

Edge Cases:
- Empty course → “Coming Soon”.
- All assets locked → availability countdown.
- API failure → retry with user message.
- Rate limiting → fallback to partial data.
```

### Chunk 15 — Roles & Permissions
```
Learner:
- Enroll, navigate, bookmark, notes, submit, request extensions.

Instructor/SME:
- Create/schedule live sessions.
- View attendance, reschedule/cancel.
- Guest link use.

Content Manager:
- Publish/unpublish assets.
- Edit drafts.
- Clone curricula.

Delivery Manager/Admin:
- Override locks.
- Approve extensions.
- Rollback versions.
- Bulk enrollment/tracks.
- View all queries.

Evaluator/Grader:
- Receives allocated assignments.
- Grades via panel (lenient/strict).
- Apply deferral tags.

Guest:
- Access via temporary URL.
- Join sessions, no submissions/dashboards.
```
