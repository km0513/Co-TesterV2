Auto-Healing Locator Strategies

1. ID-Based Locators (Highest Priority)
Most reliable - uses element ID attributes
page.locator('#submit-button')
2. Data Attribute Locators
Test-specific attributes like data-testid, data-test, data-cy
page.locator('[data-testid="login-form"]')
3. Role-Based Locators (Accessibility)
Uses ARIA roles for accessibility-friendly selection
page.get_by_role('button', name='Submit')
4. Text-Based Locators
Selects elements by visible text content
page.get_by_text('Click here to continue')
5. CSS Class Combination
Uses CSS class combinations for styling-based selection
page.locator('.btn.btn-primary.submit-btn')
6. XPath Fallback
Last resort - structural XPath locators
page.locator('xpath=//button[@type="submit"]')
